FluxLang is a lightweight programming language built specifically for Fluxer Bots.  
It focuses on clarity, minimal syntax, and fast execution — providing only the features bot developers actually need. No extra complexity, no unnecessary abstractions.

---

## What FluxLang aims to be
- A **minimal DSL** for bot logic  
- Easy to read, easy to parse, easy to compile  
- Designed to work seamlessly with FluxAsm and Fluxer’s event system  
- Small enough to implement in low‑level environments  
- Flexible enough to express real bot behavior  

---

## Example (concept syntax)
```
on "ping" -> reply "pong"
send "FluxLang online!"
```

FluxLang keeps things simple: events, actions, and optional conditions — nothing more.

---

## Why FluxLang exists
Fluxer bots don’t need a full general‑purpose language. They need:

- predictable syntax  
- fast compilation  
- minimal keywords  
- direct mapping to bot actions  

FluxLang gives you exactly that.
